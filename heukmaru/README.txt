v7에서 바뀐 것
  [물레]
  - 손: 손가락 있는 손으로 교체. 흙 옆선에 손가락 끝만 닿고 뚫지 않아요.
    벽 올리기·모양 잡기는 바깥 손 + 안쪽 손이 같은 높이에서 벽을 잡아요.
  - 누르는 높이를 따라 손이 움직이고, 흙에 노란 띠로 작업 높이를 표시해요.
  - 누르는 위치를 흙 앞면 기준으로 읽어요 (전에는 보이는 곳보다 낮게 인식됨).
  - 단계 시작 때 반투명 손이 시범 동작 2번 + 흙 위에 움직이는 화살표·설명.
    9초 동안 아무것도 안 하면 시범을 다시 보여줘요.
  - 왼쪽 '단면' 창: 벽 두께, 목표 모양(점선), 손가락 위치를 옆에서 자른 모습으로.
  - 중심 잡기: '코닝 ↑ 올려요 / ↓ 눌러요' 게이지와 횟수(●○).
  - 모양 잡기: '부풀리기 / 조이기' 버튼을 고르고 원하는 높이를 문지르면 돼요.
  - 페달: 단계마다 적정 속도로 자동 맞춤. 실전 모드는 누르는 동안 속도가 조금씩 흔들려서 페달로 바로잡아야 해요(벗어나면 빨간 테두리).
  - 벽 올리기 1~2초 타이머 링, 횟수 넘침(3/2) 버그 수정, 다듬기 도구가 흙에 닿게 수정.
  - 키보드 안내: ↑↓ 페달, Space 물, Enter 다음 단계.
  [공방]
  - 방 5개: 🏺 물레 작업실 · 🌬️ 건조·굽깎기실 · 🔥 가마실 · 🎨 시유실 · 🖼️ 전시관
    왼쪽 벽 문(표지판에 행선지)으로 걸어 다니거나, 위쪽 방 버튼으로 바로 이동.
    건조실·가마실·시유실 활동(굽깎기, 초벌·재벌, 유약 바르기, 꾸미기)은 다음 단계에서 열 예정.
  - 완성 후 '🖼 전시관에 들고 가기' → 캐릭터가 작품을 들고 걸어요 → 전시관의 빛나는 빈 받침대를 누르면 걸어가서 내려놓아요.
    '작업대에 두기'(Q)로 물레실 긴 작업대에 둘 수도 있어요.
  - NPC: 방을 오가며 선반 구경, 흙 반죽, 유약 젓기, 전시 구경. 그 자리에 맞는 말풍선.
    선생님은 물레실 3번 물레에서 계속 빚어요.

캐릭터 이미지 위치
  public/chars/  (A_ = 캐릭터 1, B_ = 캐릭터 2, N_ = 포스터 NPC)
  같은 이름으로 더 큰 해상도의 이미지를 넣으면 그대로 교체돼요.

알려진 한계
  - NPC는 포스터 컷이 한 장씩이라 걷기·작업을 통통 튀기·기우뚱 효과로 표현해요.
    NPC별 걷기 3~4컷, 작업 1~2컷이 생기면 교체할 예정.
  - 들고 걷는 컷은 정면 컷뿐이라 옆으로 걸어도 정면을 봐요.
  - 온라인 함께하기(멀티플레이)는 아직 연결 전이에요.
