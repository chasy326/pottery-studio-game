흙마루 v5 | 직접 만든 캐릭터 + 물레 성형 모드

실행
  이 폴더에서 npm start  →  http://127.0.0.1:65400
  (Node.js가 설치되어 있어야 해요)

이번 버전에서 바뀐 것
  - 플레이어 캐릭터: 직접 만든 캐릭터 시트(캐릭터 1 · 캐릭터 2)를 오려내 3D 작업실에 세웠어요.
    · 처음 들어오면 캐릭터를 고르고, 오른쪽 위 '캐릭터 바꾸기'로 언제든 바꿀 수 있어요.
    · 걷는 방향에 따라 정면 / 3/4 / 옆 / 뒤 컷이 바뀌고, 걸을 때는 걷기 컷이 움직여요.
    · '물레에 앉기'(또는 E)를 누르면 시트의 물레 차는 컷으로 바뀌어요.
  - NPC: 포스터의 도예가들을 공방 손님과 선생님으로 배치했어요 (말풍선 대화).
  - 공간·가구는 v3 3D 작업실 그대로예요.

캐릭터 이미지 위치
  public/chars/  (A_ = 캐릭터 1, B_ = 캐릭터 2, N_ = 포스터 NPC)
  같은 이름으로 더 큰 해상도의 이미지를 넣으면 그대로 교체돼요. 크기가 바뀌면 public/chars/meta.json도 함께 갱신해야 해요.

알려진 한계
  - 캐릭터는 3D 모델이 아니라 그림(스프라이트)이라, 방향 컷이 없는 각도는 가장 가까운 컷을 써요.
  - 시트 속 걷기·물레 컷은 원본 해상도가 작아서 확대하면 조금 흐려요. 컷별 고해상도 이미지가 있으면 선명해져요.
  - 뒤로 걷는 전용 컷이 없어서 뒷모습 컷이 살짝 들썩이는 방식으로 걸어요.
