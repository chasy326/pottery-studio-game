2. Key Technical Concepts:
   - Single-file HTML game, about 3.6MB, with inlined three.js r128 and base64 assets.
   - Script layers:
     - game.js core: cs3 state, craftProfile3, LatheGeometry pot, potGroup3/potMesh3/wheelGroup3/camera3/renderer3, animatePottery3D, hitPot raycast, craftMoveSub3, craftSelect3, craftAllowed3.
     - patch layer: soso-casual-patch.
     - final v3 script: sosoStageDoneFinal / `window.__sosoStageDone`, soso-final-style.
   - Overrides go in appended `<script>`/`<style>` blocks before `</body>`, via global function reassignment.
   - Gotcha: `currentTool` is a top-level `let`. It is not on `window`; read it with `try{currentTool}`.
   - Testing: Playwright with swiftshader WebGL (`--use-gl=angle --use-angle=swiftshader --enable-unsafe-swiftshader`), CDP touch events, viewport 390×844.
   - Fonts: OwnglyphRyuRyu, subset with pyftsubset into ryu-sub3.woff2 (file chars plus the 2350 KS X 1001 syllables) and embedded as a data URI.
   - Tool renders: three.js 0.160 via npm in scratchpad/tools3d.

   - Key existing game code, from the analysis:
     - `craftProfile3(r,H,f,w,foot)` returns Vector2 points:
       - starts at (0,0), then (r0,0);
       - outer wall: `V(r[i], fh+(H-fh)*i/CN)` for i=1..CN (CN=64);
       - inner rim: `V(r[CN]-w, H)`;
       - inner wall: 36 points from y=H down to f, with inner radius `cInterp(r,y/H)-w`;
       - ends at (0,f).
       - Cup example: H=.7, f=.07, w≈.074, r0=.35, potGroup3 scale ≈.676.
     - `craftRebuildMesh3()` rebuilds potMesh3.geometry from cs3.renderState and renderFoot. My trim mode must block it.
     - `craftEnterTrim3()` sets cs3.flipStart. The animate loop rotates `potGroup3.rotation.x=PI*q` over 780ms, then sets cs3.isTrim=true, currentTool='trim', step=4.
     - `craftPrimaryAction3()` routes step 4 with finishReady to craftEnterTrim3. `finishPot()` adds coins, updates the home pot and closes make mode.
     - `craftApplyRig3()`: in front view (or isTrim) the 3D wheel is hidden (`wheelGroup3.visible=!front`) and the camera is placed by binary search on cfg. potGroup3 is scaled to fit; when trimming, its position.y is `(heightScale+.02)*sc`.
     - `camera3` is PerspectiveCamera(36). The patch resets `camera3.zoom` to 1 every frame in front view and changes lastZoom.
     - `animatePottery3D` updates wheelAngle from `__sosoSpeedNow` and spins potGroup3 (+.003/frame when trimming). It then calls craftLerpState3, craftUpdateThread3, craftUpdateEffects3 and renders.
     - The visible wheel in front view is part of the background art, not the 3D wheel.
